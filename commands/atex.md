description: Initialize, inspect, or wire the native Gold/Helium AmniTex byte-page memory layer.
---

Run `atex stats` (or `atex_stats` MCP tool) to inspect the active AmniTex knowledge base, or run `atex init` and `atex install` if the current workspace is not yet indexed.

If `atex_search` is not a tool in this session, use the shell. The output matches the MCP tools:

```bash
atex search "<words>"
atex where "<words>"
atex recall <key> --query "<words>"
atex remember <key> --text "<fact>"
atex keys --prefix <prefix>
```
